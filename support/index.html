技術支援Supportサポート

常見問題。找不到答案的話，歡迎來信。

Frequently asked questions. If you can't find your answer, just write to us.

よくある質問。答えが見つからなければ、メールでどうぞ。

怎麼購買完整版？

在選職業畫面點任一個標著「完整版」的職業，或在畫廊點「完整版」的格子，就會打開購買頁。完整版一次買斷，沒有其他付費。

How do I buy the full version?

On the class screen, tap any class marked “Full version”, or tap a “Full version” tile in the Gallery, to open the purchase page. It is a single purchase with nothing else to buy.

完全版はどうやって買える？

職業選択画面で「完全版」と表示された職業、またはギャラリーの「完全版」の枠をタップすると購入画面が開く。買い切りで、ほかの課金はない。

換手機或重新安裝後，完整版不見了

打開購買頁，按下方的「恢復購買」。請用當初購買時的 Apple ID 或 Google 帳號登入。

I reinstalled or changed phones and lost the full version

Open the purchase page and tap “Restore purchase”. Make sure you are signed in with the same Apple ID or Google account you bought it with.

機種変更・再インストールで完全版が消えた

購入画面を開き、下の「購入を復元」を押す。購入したときと同じ Apple ID または Google アカウントでサインインしておくこと。

換手機時，怎麼保留遊戲紀錄？

紀錄只存在你的裝置上。換手機前：

  • 舊手機：設定 →「紀錄備份」→「複製」，把備份碼存在備忘錄或傳給自己。
  • 新手機：設定 →「紀錄備份」→ 貼上備份碼 → 按兩次「還原」。

備份碼包含通關紀錄、畫廊、燈城、餘燼與工坊，不含正在進行的那一局。

How do I keep my records when changing phones?

Your records live only on your device. Before switching:

  • Old phone: Settings → “Back up records” → “Copy”, and keep the code in your notes or send it to yourself.
  • New phone: Settings → “Back up records” → paste the code → tap “Restore” twice.

The code includes clears, gallery, Lamp City, embers and the Workshop, but not a run in progress.

機種変更のとき、記録を引き継ぐには？

記録は端末の中にだけ保存されている。機種変更の前に：

  • 古い端末：設定 →「記録のバックアップ」→「コピー」。コードをメモに保存するか、自分に送っておく。
  • 新しい端末：設定 →「記録のバックアップ」→ コードを貼り付け →「復元」を二回押す。

踏破、ギャラリー、灯城、残り火、工房が含まれる。進行中の冒険は含まれない。

怎麼操作？

  • 移動：手機用畫面上的方向鍵或搖桿（可在設定切換），電腦用方向鍵、WASD 或數字鍵。點地圖可以自動走過去。
  • 攻擊：直接走向敵人。
  • 遮燈：躲過怪物的眼睛，但視野會變小。
  • 「探索」自動走向還沒去過的地方；「搜索」撿東西、開寶箱、下樓。

遊戲裡的「說明」有完整的按鍵表與圖例。

How do I play?

  • Move: on phones, the on-screen pad or stick (switch in Settings); on computers, arrow keys, WASD or the number pad. Tap the map to walk there.
  • Attack: walk into an enemy.
  • Hood: hide from monsters, at the cost of your sight.
  • “Explore” walks toward unexplored areas; “Search” picks things up, opens chests and takes the stairs.

In-game “Help” has the full key list and legend.

操作方法は？

  • 移動：スマホは画面の方向キーかスティック（設定で切り替え）、パソコンは矢印キー、WASD、テンキー。マップをタップするとそこまで歩く。
  • 攻撃：敵に向かって歩く。
  • 遮灯：怪物の目を逃れるが、視界が狭くなる。
  • 「探索」は未踏の場所へ自動で進み、「捜索」で拾う・宝箱を開ける・階段を下りる。

ゲーム内の「説明」にキー一覧と凡例がある。

需要連網嗎？

不需要。遊戲完全離線，不需要帳號，也不收集任何資料（見隱私權政策）。

Do I need an internet connection?

No. The game is fully offline, needs no account and collects no data (see the privacy policy).

通信は必要？

不要。完全にオフラインで、アカウントも不要、データも収集しない（プライバシーポリシーを参照）。

Report a problem or send feedback

Write to hello@sanbaofang.com. For problems, please include your device model, OS version and the game version shown on the About page; a screenshot helps.

不具合の報告・ご意見

hello@sanbaofang.com までどうぞ。不具合の場合は、端末の機種、OS のバージョン、ゲームの「このゲームについて」画面のバージョンを添えてほしい。スクリーンショットがあると助かる。
