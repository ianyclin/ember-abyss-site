# 燼燈深淵 Emberlamp Abyss：官方網站

https://ember.sanbaofang.com/

- `/`：首頁
- `/support/`：技術支援（App Store 的 Support URL）
- `/privacy/`：隱私權政策（App Store／Google Play 的 Privacy Policy URL）

三頁都有繁中、English、日本語（`?lang=zh-Hant|en|ja`，或右上角切換）。

改內容：編輯 `build.py`（首頁與支援）或 `privacy-src.html`（隱私權政策），再執行 `python3 build.py` 重新產生三頁。
不載入任何外部字型、分析或追蹤工具。

Cloudflare Pages：Production branch `main`、Build command 空白、Build output directory 空白、Custom domain `ember.sanbaofang.com`。
